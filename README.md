# Movie Discovery — Discover Your Next Favorite 🎬

MOVIE DISCOVERY is a movie discovery website I built as part of the Full-Stack Intern assignment.

I started with my own basic UI and manually listed the stack of movies and then used AI to help me enhance the UI, make it more responsive, and understand how to integrate the TMDB API properly. I used Node.js and Express as a backend layer so the API key isn't exposed directly in the frontend.

# What I built

- Movie search using TMDB
- Genre filtering and sorting
- Movie details
- Pagination / load more
- Wishlist with persistent storage
- Responsive UI for different screen sizes
- Loading, empty and error states

### Tech Used

HTML, CSS, JavaScript, Node.js, Express.js, Axios and TMDB API.
